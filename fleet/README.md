# Fleet gallery

The public page is `/fleet/`. It starts with the existing real JWC hauling photograph. No stock photos or additional trucks/trailers are represented.

For each new approved photo, save it under `assets/fleet/` with a descriptive filename and add a `figure.fleet-photo` to `.fleet-gallery` in `index.html`. Set `data-categories="trucks"`, `"trailers"`, or `"trucks trailers"`. Use accurate alternative text, a caption, and the image's actual width/height. Link the photo to its original for full-size viewing. The filters work with those categories, and the photos remain available without JavaScript. Preserve the mobile image proportions so equipment is not heavily cropped.

Remove the coming-soon message when the initial collection is in place. Do not invent equipment specifications, capacities, unit numbers or fleet counts.
